Dreamway Education
Pakistan's Premier Study Abroad Consultancy


Overview

Dreamway Education is a fully responsive, modern website for a professional study abroad consultancy based in Lahore, Pakistan. The platform helps Pakistani students discover universities, explore study destinations, and book free consultations — all through a premium, world-class web experience.

---

Features

- Premium UI/UX with custom Teal and Deep Blue brand identity
- 15 study destinations with detailed country pages
- Fully responsive across mobile, tablet, and desktop
- Smooth animations powered by Framer Motion
- Animated counters, custom carousel, and masonry grid layout
- SEO optimized with Open Graph, Twitter Cards, and Schema.org
- Contact form with WhatsApp integration and Google Maps embed
- Multi-page routing with React Router v6
- Glassmorphism sticky navbar with mobile hamburger menu
- Custom 404 page

---

Brand Identity

Primary Color   Teal         #23AAA6   Buttons, links, highlights
Secondary Color Deep Blue    #265D96   Gradients, icons, accents
Accent Color    Terracotta   #C97E5E   Badges, stars, rare CTAs

Typography
- Display: Fraunces (serif) — headings
- Body: Plus Jakarta Sans (sans-serif) — all UI text

---

Pages

Home            /                     Hero, Stats, Services, Countries, Process, Why Us, Testimonials, FAQ, CTA
Countries       /countries            All 15 destinations with region filter
Country Detail  /countries/:slug      Per-country info, universities, programs, requirements
About           /about                Mission, values, timeline, team
Testimonials    /testimonials         Masonry grid with country filter
Contact         /contact              Form, WhatsApp, map, office hours, socials
Not Found       *                     Custom 404 page

---

Tech Stack

React 19, Vite, Tailwind CSS v4, Framer Motion, React Router v6, Embla Carousel, React Icons

---

Getting Started

Requirements: Node.js v18+

Installation:

    git clone https://github.com/ali-developer/dreamwayeducation.git
    cd dreamway-education
    npm install
    npm run dev

Production Build:

    npm run build
